# Практическая работа № 5
## «Блочная вёрстка макетов, ролловерная навигация и относительное позиционирование»

###Тема: Создание макетов веб-страниц с помощью CSS без табличной вёрстки, применение позиционирования и плавающих блоков, оформление ссылок и списков, создание вертикального меню с rollover-эффектом и горизонтальной панели навигации.

### Цель: Научиться применять блочную модель CSS, создавать двухколоночные макеты, оформлять гиперссылки и списки, использовать относительное позиционирование и подключать фоновые изображения.

### Задача: Создать три веб-страницы по материалам практической работы № 5:

1. **«История Минска»** — центрированный макет с левой панелью навигации и основным содержимым.
2. **Вертикальная панель навигации** — меню с кнопками и rollover-эффектом при наведении.
3. **«Фонтаны Минска»** — страница с горизонтальной панелью навигации и изображениями.

Требования к заданиям приведены в файле `ПРАКТИЧЕСКАЯ РАБОТА5.pdf`.

## ⚠️ Критические требования к качеству кода

При проверке работ Виталий Валентинович оценивает не только визуальное соответствие макету, но и архитектурную чистоту CSS-кода:

- **Избегайте «побочных свойств» при сокращениях:** Если вам нужно переопределить исключительно цвет фона, используйте целенаправленное свойство `background-color`, а не общее `background`. Использование общего свойства сбрасывает все остальные параметры фона (размер, повторение, позицию) в значения `initial`, что усложняет поддержку кода.

- **Правильные пути к медиафайлам в CSS:** Помните, что пути к картинкам внутри файла `style.css` рассчитываются относительно самого CSS-файла, а не HTML-страницы. Используйте выход на уровень выше, если папка с картинками лежит в корне проекта: `background-image: url(../images/rol.gif);`.

- **Контроль схлопывания отступов (Margin Collapsing):** Вертикальные внешние поля соседних или вложенных блочных элементов могут объединяться в одно общее поле, равное наибольшему из них. Если вам необходимо избежать незапланированного сдвига или объединения margins, разделяйте блоки внутренними отступами (`padding`) или рамками (`border`).
