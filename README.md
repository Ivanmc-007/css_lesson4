# Практическая работа № 5
## «Блочная вёрстка макетов, ролловерная навигация и относительное позиционирование»

**Тема и Цель:** Проектирование многоблочных макетов без таблиц, создание интерактивных меню на основе CSS-эффектов и управление графикой через `position: relative`.

## Вёрстка веб-страницы
* Задача: используя возможности CSS по позиционированию блоков, создать макет веб- страницы, не прибегая к устаревшей табличной разметке.

## 🛠️ Выполнение работы и структура проекта
Каждый студент работает строго внутри персональной директории в `pages/` (например, `pages/fufaev/`), чтобы избежать конфликтов слияния. Исходные изображения остаются в общей папке `images/`.

Финальная структура:
```text
css_lesson4/
├── index.html
├── README.md
├── images/
└── pages/
    └── fufaev/
        ├── index.html
        ├── fountains.html
        └── css/
            └── style.css
```
